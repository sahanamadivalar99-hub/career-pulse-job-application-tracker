System Architecture & Database Status
Technology Stack
Java 21, Spring Boot 3.3.4, Spring MVC, Spring Data JPA, Hibernate, Thymeleaf, Apache PDFBox 3.0.3.
MySQL Configuration
Database: job_tracker_db on port 3306. Profile: application-mysql.properties.
Dual Database Support: Zero-setup file persistence is enabled by default so the application runs out-of-the-box. To switch to local MySQL, start MySQL and start Spring Boot with --spring.profiles.active=mysql.
